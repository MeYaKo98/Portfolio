This project involves designing and building an autonomous quadcopter capable of navigating cluttered forest environments without GPS assistance. The drone uses onboard sensors to map its surroundings, plan collision-free paths, and stabilize itself in variable wind conditions.

The system utilizes a lightweight carbon-fiber frame equipped with an onboard companion computer (NVIDIA Jetson) running ROS. Environment sensing is performed via a solid-state LiDAR and a stereo camera, feeding a real-time SLAM (Simultaneous Localization and Mapping) algorithm.

Core engineering components:
· Path planning utilizing A* and dynamic window approach (DWA) for reactive avoidance
· Custom flight controller firmware with PID control loops for attitude and altitude stabilization
· Odometry fusion of optical flow, IMU, and LiDAR data using Extended Kalman Filters (EKF)
· Low-level C programming on microcontroller flight processors
