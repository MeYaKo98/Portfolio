The Eurobot AV Dashboard is a comprehensive competition management platform I developed using ReactJS, Node.js, Express.js, MongoDB, and Socket.IO. It serves as the central system for managing live scoring, team coordination, and real-time display control during Eurobot international robotics competitions.

Key features include:
· Role-Based Access Control: Four specialized user roles (Admin, Referee, AV Team, Visitor) with tailored interfaces for match management, scoring entry, display control, and live viewing
· Real-Time Match Management: Live score submission, match scheduling, round progression, and finals bracket management with instant synchronization across all connected clients
· Dynamic Task-Based Scoring: Configurable task definitions with automatic score calculation based on task completion status
· Public Display System: Professional live broadcast interface controlled by AV team, featuring countdowns, match banners, team information, and final scores
· WebSocket Real-Time Events: Socket.IO-powered bidirectional communication for instantaneous match status updates, timer management, and score broadcasts
· Multi-Page Architecture: Specialized pages for Control Center (admin), Referee Interface (scoring), Dashboard AV (broadcast control), Scores Display (public results), and User Management
· Secure Authentication: JWT-based authentication with bcrypt password hashing and role-based authorization middleware
· Docker Containerization: Full containerized deployment with Docker Compose for reliable, scalable multi-container orchestration across development and production environments

The platform demonstrates advanced full-stack web development expertise, real-time communication patterns, enterprise-level role-based access control, and production-ready deployment strategies. It successfully manages complex competition workflows while ensuring seamless user experiences for both operational teams and public audiences at major international robotics events.
