The Eurobot Score Stream Overlay is a professional scoring and streaming platform I developed using ReactJS, Express.js, and MongoDB for the Eurobot 2019 competition. It centralizes match data input and display with real-time streaming overlays.

Key features include:
· Scoring Dashboard: Intuitive interface for streamers to manage match data and live overlays
· Real-time Overlays: Socket.IO-powered live visuals displaying scores, countdowns, and round details with smooth animations
· Multi-User Authentication: JWT-based authentication with four user roles - visitor, streamer, referee, and admin
· OBS Integration: Seamless integration with OBS Studio for professional stream overlays
· Docker Deployment: Containerized deployment enabling easy setup and platform customization for each competition edition

The platform received positive feedback from viewers and referees for its professionalism and ease of use, significantly enhancing the viewing experience during matches. It demonstrates expertise in full-stack web development, real-time communication, and UI/UX design for specialized applications.
