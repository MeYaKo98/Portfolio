Overview

The Motion Robotics Framework is a lightweight, high-performance C++ robotics framework for embedded microcontrollers. Built with a pure interface-driven architecture, each component—actuators, sensors, controllers, odometry, and motion profiles—derives from virtual base classes, enabling seamless composition and extensibility. This design decouples hardware implementation from motion control logic, allowing developers to integrate custom hardware drivers, novel control algorithms, and specialized protocols without modifying core logic. Optimized for real-time performance across ESP32, STM32, and Arduino platforms with native PlatformIO support.

Architecture Layers

Core Components

Core Layers

IO Layer: Virtual base classes for actuators (motors, servos, steppers), sensors (encoders, IMUs, LiDAR), and communication channels (Serial, TCP/IP, extensible to BLE/LoRaWAN).
Robot Layer: Extensible odometry (differential drive, Ackermann, mecanum), navigation orchestration, pluggable controllers (PID, LQR, MPC), motion profiles (trapezoidal, splines), and stop conditions (settle, oscillation, time-based).
Link Middleware: Abstracts communication protocols for remote telemetry, command injection, and real-time robot monitoring.

Key Features

  • Interface-Driven Extensibility: Virtual base classes enable custom implementations for any component without modifying core logic.
  • Real-Time Performance: Lock-free designs and efficient interrupt handling ensure deterministic control across all configurations.
  • Low Memory Footprint: Optimized for resource-constrained microcontrollers with minimal code bloat from dynamic polymorphism.

Composition-Based Design

Each component is independently swappable: implement custom odometry for new drive types, extend profile generators for novel trajectories, or add sensors/actuators by implementing the appropriate virtual interfaces. The framework automatically composes these implementations without modification to core logic.

Motion Studio: VS Code Extension

Complementing the Motion Framework is Motion Studio, a comprehensive VS Code extension that provides device control, communication tooling, and live debugging capabilities for any Motion Framework-based robot, regardless of drive type, controller, or sensor configuration.

Motion Studio Features

  • Multi-Protocol Support: TCP/IP or Serial with automatic device discovery (Bonjour/mDNS).
  • Interactive CLI: TypeScript-based terminal interface for Motion Protocol commands.
  • Binary Protocol: Type-safe serialization/deserialization with extensible command support (getstatus, getposition, moveto, orient, stop, custom commands).
  • Developer Tools: Command history, context-aware help, and live logging for rapid debugging.

Integrated Ecosystem

  • Reliable Firmware: Motor control, odometry, and sensor fusion cleanly isolated on microcontroller.
  • Live Debugging: Remote telemetry and command execution without re-compile/flash cycles.
  • Extensible Design: Add drive types, sensors, controllers, and protocols without modifying core code.
  • Type-Safe Communication: Packed binary protocol with strict validation prevents transmission errors.
